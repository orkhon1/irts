# Сурагчдын ирцийн систем

Өглөөний болон өдрийн ээлжийн ирцийн бүртгэл. GitHub Pages-д шууд байршуулах статик хувилбар.

## Нийтлэх

1. Энэ хавтасны файлуудыг GitHub repository-ийн main салбарын үндсэн хавтаст оруулна.
2. Settings → Pages → Deploy from a branch → main → /(root) → Save.
3. GitHub Pages-ийн өгсөн хаягаар нээнэ. Хоёрдугаар ээлж index2.html хуудастай.

.nojekyll файл нь бэлэн HTML/CSS/JS файлуудыг шууд нийтэлнэ.

## Мэдээлэл хадгалах

Google Sheets / Apps Script-ийн одоогийн серверийг ашиглана. Apps Script-ийн Code.gs нь энэ нийтлэх багцад ороогүй.

Энэ нь нийтэд нээлттэй хувилбар: сурагчдын жагсаалт, JavaScript дахь одоогийн Sheets token нь нийтлэгдсэн файлуудаас харагдана. Нэвтрэх эрх шалгах хамгаалалт одоогоор байхгүй.
